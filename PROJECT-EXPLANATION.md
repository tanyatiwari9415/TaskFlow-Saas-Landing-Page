# TaskFlow – Project Explanation

TaskFlow is a responsive SaaS landing page designed for a task management platform.

I used HTML, CSS, and JavaScript to build this project. The main goal was to create a clean, simple, and user-friendly interface.

The website includes a navigation bar, hero section, features, how it works, pricing plans, and contact form.

I also implemented a functional task manager where users can add, complete, delete, and filter tasks.

Local Storage is used to save tasks even after refreshing the page.

One challenge was making the website responsive and ensuring all interactive features worked properly.

I learned how to build a responsive website and implement JavaScript functionality through this project.
